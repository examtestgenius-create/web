# StudyHub Apps Script Backend

Paste the .gs files in this folder into Apps Script (Extensions → Apps Script).
Deploy as Web App.
Set Script Properties:
- SITE_BASE_URL
- NOTIFY_EMAIL
- PAYFAST_MERCHANT_ID
- PAYFAST_MERCHANT_KEY
- PAYFAST_PASSPHRASE (optional)
- SHEET_ID (optional)

Then paste the Web App URL into `config.js` (webappUrl).
