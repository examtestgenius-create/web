# 20 Minute Deploy

1. Upload all root files to GitHub repo.
2. GitHub Settings → Pages → Deploy from branch → main → root.
3. Keep `CNAME` for `examtestpaper.co.za`.
4. Copy `/apps_script/*.gs` into Google Apps Script project.
5. Add PayFast secrets in Script Properties.
6. Run backend setup and catalog build.
7. Test Buy -> PayFast.
