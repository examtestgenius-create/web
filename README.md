# StudyHub Website (v1.1)

Includes legal pages and SEO files:

- `privacy.html`
- `terms.html`
- `robots.txt`
- `sitemap.xml`
- `404.html`

## PayFast config
Copy `assets/js/config.example.js` to `assets/js/config.js` and fill your credentials.

## IMPORTANT (SEO)
Replace `YOUR_USERNAME` and `studyhub-site` inside:

- `robots.txt`
- `sitemap.xml`
- `<link rel="canonical">` tags in `index.html` and `catalog.html`

Then submit sitemap in Google Search Console:

`https://YOUR_USERNAME.github.io/studyhub-site/sitemap.xml`
