How it works

From source link to package delivery

01

Queue

Direct PDF or ZIP links are added with grade, subject, province, year and document metadata.

02

Process

The backend validates links, downloads files, hashes them and records them in the library.

03

Bundle

Package rows are built from metadata and ZIP files can be generated for active packages.

04

Publish

The frontend reads the exported live catalog feed and renders featured cards, search, filters and package pages.
