# StudyHub Public Website REV2

## Major changes
- Complete modern study-tech visual redesign.
- Live Catalog is now the only public product source.
- Removed sample Catalog fallback from public loading.
- Dynamic Grade 9, 10, 11 and 12 filters.
- Dynamic featured bundles based on live verified Catalog rows.
- Improved mobile layout, product cards, grade navigation and empty states.
- Product cards show verified pair count, file count, actual years and live price.
- Existing checkout, package details, PayFast backend and legal pages are retained.

## Go-live rule
Only Catalog rows with `published=TRUE` and `zip_status=READY` appear publicly.
